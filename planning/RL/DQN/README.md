# binpacking_Tetris3D

물류 적재 관련 문제를 강화학습으로 풀기 위한 연구용 코드입니다.

현 코드는 오픈소스로 배포된 [2D Tetris 강화학습 코드](https://github.com/uvipen/Tetris-DQN-pytorch.git)를 기반으로 3D로 확장한 버전입니다.

## 파일 구성

### 2D Tetris 관련 파일 (참고용)
- `train.py`
- `test.py`
- `src/model.py`
- `src/tetris.py`

### 3D Tetris 관련 파일 (확장된 코드)
- `train3D.py`
- `test3D.py`
- `src/model3D.py`
- `src/tetris3D.py`
